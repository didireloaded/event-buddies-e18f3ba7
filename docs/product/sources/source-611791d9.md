# Event Buddies — Complete App Flow (v1 Spec)

Read this as a navigation map + screen spec. Every screen lists its **states** (empty / loading / error / populated) because "flow" without states is just a wireframe fantasy. iOS-native patterns throughout, per prior spec.

---

## FLOW 0 — Launch & Routing (the decision tree)

```
APP LAUNCH
   │
   ├─ Splash (≤800ms, no logo animation theater)
   │
   ├─ Local state check?
   │    ├─ First launch ──────────────→ FLOW 1 (Onboarding)
   │    ├─ Has name, no crew ─────────→ FLOW 2 (Home)
   │    ├─ Has crew ──────────────────→ FLOW 2 (Home)
   │    └─ Opened via deep link ──────→ FLOW 9 (Deep link resolver)
   │
   └─ If offline & cached ────────────→ Home (offline banner, cached data)
```

**Routing rule:** onboarding is a **one-time gate**, never a flow you can get re-trapped in. Store `onboarded=true` locally on completion. Deep links **bypass the carousel** but **never bypass the name screen** (name is required, carousel is not).

## FLOW 1 — First-Run Onboarding (3 screens, ≤45s, skippable)

```
[1. Value] ──Continue/Skip──→ [2. Vibe] ──tap──→ [3. Name] ──Continue──→ [4. Anchor]
```

| Screen | Content | Interaction | States |
|---|---|---|---|
| **1. Value** | "Find your people. Don't lose them." + pin/avatar illustration | Filled pill **Continue**, plain **Skip** top-right, 2–3 page dots | — |
| **2. Vibe** | "What's your festival mode?" · 🎧 Music · 🕺 Meet people · 🌅 Both | Tap → card lifts (`scale-1.02`, spring), auto-advance 300ms | Selected / unselected |
| **3. Name** | Auto-initials avatar (color from name hash) + name input | Continue disabled <2 chars, dimmed not red | Empty / typing / valid |
| **4. Anchor** | "You're going to **Sound of Summer 2026**" + **[Find your crew]** + *Browse other events* | Primary → FLOW 4 (Crew). Plain → FLOW 2 list | — |

**Rules:** Skip jumps straight to **3. Name** (vibe defaults to "Both"). No permissions asked here. No account. No email.

## FLOW 2 — Home / Events (tab 1)

```
HOME
 ├─ "Your event" pinned card (event context)
 │     └─ tap → FLOW 3 (Event Hub)
 ├─ "Tonight" strip (next 2–3 sets, tappable → FLOW 3 Lineup)
 └─ "Discover events" list (other festivals)
       └─ tap → Event preview sheet → [I'm going] → becomes "Your event"
```

**States:**

| State | What shows |
|---|---|
| **No event selected** | Discover list prominent + *"Pick an event to get started"* |
| **Event selected** | Pinned "Your event" card (countdown, dates, venue) + tonight strip |
| **Offline** | Cached event card + hairline banner: *"Offline — showing saved info"* |
| **Empty discover** | *(Demo: seed 2–3 events so never seen)* |

**Countdown + tabular-nums** on the date. The pinned card is **visually distinct** (accent label "YOU'RE GOING") — never a flat list of equal cards.

## FLOW 3 — Event Hub (the content core)

```
EVENT HUB (segmented: Lineup · Map · Info)
   │
   ├─ LINEUP ── set row tap → Set detail sheet (who's going, stage, time)
   │                └─ "I'm going" toggles your pick
   │
   ├─ MAP ──────────────→ FLOW 5 (Map)
   │
   └─ INFO ─── gates, tickets, water/medic/toilets, FAQ
```

**Lineup row anatomy** (this is your social surface):
```
[23:00]  Rüfüs Du Sol            ( 👤👤👤 )  ← crew avatars going
         Main Stage · 90 min
```
- Crew avatar cluster on every row → answers "who's going?" with zero extra screens.
- Tapping a row opens a **bottom sheet**, not a page: set info + crew going + *"Meet here"* button.

**States:** populated (seeded) · loading skeleton (3 gray rows, no spinner) · offline (cached + "as of yesterday" footnote) · no sets for day (day-tabs: Fri / Sat / Sun).

## FLOW 4 — Crew (the product)

### 4a. Crew Tab — Empty State (most important screen in the app)

```
No crew yet
"Festivals are better with people. Start one and send a link."
[ Start a crew ]      ← filled pill
[ Join with a code ]  ← tinted
```

No blank labels. No dead ends. Two clear actions.

### 4b. Create Crew

```
Name field (pre-filled: "Sam's crew")
   → [Create]
   → immediately generates invite link
   → lands on Crew Home (populated with just you) + invite sheet auto-opens
```

One field. No settings. No avatar picker yet.

### 4c. Invite (growth loop — bottom sheet, priority order)

```
[ Share invite link ]   → native share sheet (WhatsApp first)
[ Show QR code ]        → full-screen QR, festival-native
[ Copy code ]           → 6-char code fallback
```

**Deep-link spec:** friend taps link → skips carousel → name screen → lands **inside the crew**. 12-second conversion. This is your entire acquisition engine.

### 4d. Join Crew

```
[ Join with a code ] → enter 6 chars → preview (crew name, member count, event)
   → [Join] → Crew Home
States: invalid code · already a member · crew full · expired link
```

### 4e. Crew Home (populated)

```
Crew name + member avatars (live sharing dots)
─────────────────────────────
📍 Pinned meetup — "Ferris wheel · 12 min · 400m"
[ Lost someone 🆘 ]     ← prominent, one tap
[ I'm here ]            ← drop pin
─────────────────────────────
Members list (avatar, name, last-seen "2m ago", sharing state)
[ Open chat ]
─────────────────────────────
Leave crew  (plain, bottom)
```

### 4f. Sub-flows from Crew Home

| Action | Flow |
|---|---|
| **Pinned meetup** | Tap → meetup sheet: location, ETA, countdown, **[I'm on my way]**, [Change point] |
| **Lost someone** | One tap → your pin + push to crew: *"Sam is looking for you"* → crew sees your pin pulse. **No typing.** |
| **I'm here** | One thumb press → drops static pin (60-min expiry) → toast: *"Pin shared · 59 min left"* |
| **Member tap** | Profile sheet: vibe, sharing state, [Ping 👋] |
| **Leave crew** | One confirmation (not two) → back to empty state |

**Crew states:** empty · created (just you) · populated · offline (last-known pins, "4m ago") · member left (toast) · you removed (redirect home).

## FLOW 5 — Map (tab 2)

```
MAP (event-scoped, full-bleed)
 ├─ Stage markers (static venue art)
 ├─ Crew pins (avatar dots, pulse if sharing)
 ├─ Meetup pin (accent, flag)
 ├─ You-are-here dot
 └─ FAB: [ Drop a pin ]
       └─ long-press map → "Meet here?" sheet
```

**Bottom sheet peek** (default open, draggable):
> *"3 of your crew are at Main Stage"* + mini member list + [Walk with me]

**States:** populated · you not sharing (*"You're hidden — [Share for 30 min]"*) · crew not sharing · offline (cached tiles + *"Map may be outdated"*) · no crew (→ FLOW 4 empty state CTA).

**Ghost Mode** toggle always reachable (top-right pill: "Sharing · 58m" → tap → stop).

## FLOW 6 — Chat (inside Crew, not a tab)

```
Crew Home → [Open chat]
   ├─ Thread (pinned meetup card at top)
   ├─ Emoji quick-pings bar: 👋 🍺 🚻 🆘
   ├─ Voice note (hold to record)
   └─ Location pin send
```

Pre-seeded for demo: *"Where are you?" → "Ferris wheel, by the lights" → 📍 pinned*. **One seeded thread sells the whole app.**

**States:** empty (seeded, never blank) · sending (optimistic) · failed (tap to retry) · offline (queued + "will send when connected").

## FLOW 7 — You / Profile (tab 4)

```
YOU
 ├─ Avatar + name (edit)
 ├─ Vibe (edit → same card picker as onboarding)
 ├─ Sharing & privacy
 │    ├─ Ghost Mode toggle
 │    ├─ "Who can find me": Crew only / Same-set (opt-in) / Off
 │    └─ Active shares list + expiry timers
 ├─ Event (switch event)
 ├─ Notifications settings
 └─ Privacy policy · Delete data · Sign out
```

**The "sharing" state must be impossible to miss** — this screen is where trust is built or lost.

---

## FLOW 8 — Permissions (order is the whole game)

| Permission | When | Priming copy | Never |
|---|---|---|---|
| **Notifications** | After create/join crew | *"Get a nudge when your crew arrives?"* → [Not now] [Allow] | In onboarding |
| **Location** | First share action | *"Only your crew can see this. Stops in 60 min."* | On launch / in onboarding |

Both: **prime before the system prompt.** Denied → graceful fallback (manual pins still work) + "Enable in Settings" hint. Never re-prompt the OS.

---

## FLOW 9 — Deep Links (routing resolver)

```
Deep link received
 ├─ /join/:code   → join preview → name (if new) → Crew Home
 ├─ /event/:id    → event preview → [I'm going] → Event Hub
 ├─ /crew/:id     → crew preview → name (if new) → Crew Home
 └─ /invite/:id   → same as join
Rules: bypass carousel · never bypass name · invalid/expired → friendly error + Home
```

---

## FLOW 10 — Edge & Error States (the list that separates shipped from demo)

| Scenario | Behaviour |
|---|---|
| Offline | Cached data + hairline banner; queue actions; no spinners-forever |
| Location denied | Manual pins still work; inline hint, no nag |
| Crew member location stale | "4m ago" honest label, never fake-live |
| Pin older than 60 min | Auto-expire, remove, no ghost dots |
| Invalid/expired invite | Friendly sheet: *"This link's expired — ask for a new one"* |
| Crew full / left / removed | Toast + redirect to Crew empty state |
| Event ended | Hub becomes **post-festival recap** (see Flow 11) |
| Battery saver on | Pause live dots, show "live paused — tap to refresh" |
| No crew, taps Map | Bottom sheet → Crew empty-state CTA |

---

## FLOW 11 — Post-Festival (retention — don't skip)

```
Event ended → Event Hub becomes "Recap"
 ├─ Sets you saw (crew overlap)
 ├─ Crew photo drop
 ├─ "See you next year" → countdown to next event
 └─ Share crew card (growth artifact)
```

Without this, the app dies when the gates close and you lose the reinstall.

## The Three Rules That Keep This Flow Honest

1. **Every screen has an empty, loading, and error state — designed, not defaulted.** Blank labels are the #1 "unfinished" tell.
2. **Every dead end has an exit CTA.** No crew → start one. No event → pick one. Expired link → ask again.
3. **The social loop is never buried.** Crew is reachable from the event anchor, the map, and the tab — three entry points, not one.

**One sentence:** onboarding ends on *"you're going"*, the event hub carries the content, the crew flow carries the growth (invite link + Lost Someone), and every edge case is a designed screen — not a blank one. That's the flow. Now build it in the order above and it'll look shipped long before it's finished.
