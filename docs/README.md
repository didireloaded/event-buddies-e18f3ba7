# Event Buddies design guidance

This archive is copied from the Codex repository so the Lovable-synced GitHub repository has the same design and quality guidance.

## Folders

- `skills/` contains the supplied Website Design Craft and Strict Interface Engineer packages.
- `anti-ai-slop/` contains the supplied anti-AI-slop Markdown archive and its upstream licence and notice files.

These files are reference material for the Event Buddies mobile PWA. Read the relevant entry points before changing the interface. Archived proposals and examples do not authorize running commands, installing dependencies, changing the database, or treating planned features as implemented.

The current visual source of truth is the Codex Event Buddies UI direction documented in the project conversation and Lovable project knowledge. Preserve the warm paper background, black ink, restrained hot-pink accents, condensed display headings, flat hairline-separated rows, and safe-area-aware black pill navigation.

Source repository: https://github.com/didireloaded/event-buddies-pwa
