# Mobile App Builder

This is a self-contained mobile-app development skill distilled from the design, anti-slop, engineering, accessibility, security, testing, review, writing, and workflow materials in the ANTI AI SLOP library.

It is intended for use in other IDEs without attaching or copying the original reference folder.

It supports:

- React Native and Expo
- SwiftUI and UIKit
- Jetpack Compose and Android Views
- mobile web and PWA
- shared web/native products

## Install

Copy the `mobile-app-builder` folder into the skill directory supported by your IDE or coding agent. Common locations include:

```text
~/.agents/skills/
~/.codex/skills/
```

The skill is self-contained and does not require `/Users/visionhaus/Documents/ANTI AI SLOP/` to exist on the destination machine.

## Use

Invoke it explicitly where supported:

```text
Use the mobile-app-builder skill for this task.
```

Or add the contents of `SKILL.md` to the IDE’s project-level agent instructions.
